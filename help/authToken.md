# Authorization and account safety

CordWipe does not ask you to copy an authorization token from DevTools. Never paste a Discord token into a chat, issue, screenshot, or third-party website. Tokens grant access to your account.

The **Fill** button explicitly retrieves authorization. **Delete** retrieves it if you have not used Fill. Neither action should be needed to inspect the panel. Review the source before installing and do not use unreviewed scripts or console-paste instructions.

See [CordWipe safety and privacy](../README.md#safety-and-privacy).
